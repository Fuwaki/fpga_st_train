# v9 — guided 单图过拟合：笔触死在全分辨率头，不在通道宽度

日期 2026-10-23。配置在 `experiments/tiny_dw_vangogh_overfit/`。

问的是 `tiny_dw_guided` 的表达上限，以及 V1 为什么在同一张图上比 V2 差一截。
教师是 MicroAST、梵高《星夜》。内容是 `demo_inputs/city.jpg` 长边 640（实际 640×424），
`data.overfit_long_edge = 640`：不随机裁剪，教师目标在第 1 步算完后缓存。
损失 `1·L1 + 2·grad`，学习率 6e-4 常数，seed 0。cohort 共用一次教师前向。

采样指标对这张图的教师：`lapvar_teacher = 0.00632`。
`lapvar` 比 = 学生拉普拉斯能量 / 教师。
`e4-8`、`e8-16` = 该频段能量 / 教师同频段能量。

---

## 0. 结论

1. **V1 的断崖不是 `up_h2 = 24`。** 半分辨率收到 24 通道、头保持 V2（`full = 0`，可分离 8→3，输出无 ReLU），1000 步和 V2 重合：PSNR 23.74 对 23.55 dB，`e4-8` 都是 0.32，`e8-16` 0.66 对 0.64。
2. **断崖跟的是 `full = 16` 那条头。** 可分离层输出带 ReLU，RGB 用 1×1。半分辨率保持 48、`film_full` 关掉，1000 步仍是 20.32 dB、`e8-16` 0.16、lapvar 比 0.04，和 V1 在同一步的 20.14 dB / 0.14 / 0.03 同一档。梯度损失从第 100 步的 0.067 到第 1000 步仍是 0.065，几乎没动。
3. **`film_full` 没有把主干按死。** 同一条 `full = 16` 的头把 `film_full` 打开，反而是这轮最好的一臂：24.19 dB，`e8-16` 0.76，`e4-8` 0.41，lapvar 比 0.17。超过 V2 在第 1000 步的 23.55 / 0.64 / 0.32 / 0.10，lapvar 比已经到 V2 第 2000 步的水平（0.18）。FiLM 加在那层 ReLU 之后，β 可以把特征重新推回带符号，1×1 才有负向残差可用。
4. **`full16` 和 `full16_film` 的初值不是同一份。** `Film::new` 在 `GuidedStudent::new` 里排在 stem 之前，会先消耗初始化随机数，后面每一层的初值都跟着变。主结论不靠这一对：V1（2000 步，另一份初值）和 `full16` 的曲线同形，V2 和 `h2_24` 同形。若要单独给 `film_full` 定性，得把 FiLM 的构造挪到主干之后再重跑这一对。
5. **中笔触已经接近 `film_both`，细笔触和锐度还差一倍，而且不是 8 通道或 2×2 色块卡住的。** `film_both` 第 1000 步是 25.59 dB、lapvar 比 0.39、`e4-8` 0.79、`e8-16` 0.82。只换最后一次上采样的 `shuffle_guide` 把 `e4-8` 从 V2 的 0.32 抬到 0.42，和 V2 再训 1000 步的终点一样，checker 却到了 8.9e-6（教师约 1e-6）。guide 加宽到 16 通道与 V2 重合。guide 去掉 ReLU 则躺平到 19.87 dB、lapvar 比 0.02。
6. **4–8 px 卡在主干格点。** 把 `film_both` 的残差推到 H/8 之后，`e4-8` 从 0.79 掉到 0.22，全分辨率 stem 和 64 通道 H/2 跳连都还在。guided 把残差留在 H/4、并保留 `h2_guide=16`，第 1000 步到 25.05 dB / lapvar 比 0.22 / `e4-8` 0.68 / `e8-16` 0.78。8–16 px 已经对齐 `film_both` 的 0.82。剩下的是 1–3 px 的锐度，lapvar 比 0.22 对 0.39。

## 1. 两条头

两边主干相同：2×2 平均池化后 stem，H/8 上 64 通道加一个 ResBlock 和 InstanceNorm，再最近邻爬回半分辨率。差别在半分辨率宽度和全分辨率怎么写出 RGB。

| | `up_h2` | 全分辨率 | RGB 头 | 输出 ReLU |
|---|---:|---|---|---|
| V2 / `h2_24` | 48 或 24 | 无 | 可分离 8→3 | 无（深度卷积后仍有 ReLU） |
| V1 / `full16` | 24 或 48 | 可分离 8→16，可选 FiLM | 1×1，16→3 | `full_sep` 的输出有 ReLU |
| `film_both` | 48（`tiny_dw` 的 mid） | 可分离 48→24 + FiLM | 可分离 24→3 | 头的输出无 ReLU |

`film_both` 另外保留 64 通道的 H/2 内容跳连，主干停在 H/4，stem 在全分辨率。guided 没有跳连，主干在 H/8，全分辨率重读的是原图 RGB（3→8 的 guide，再加到放大后的 8 通道颜料上）。

|---|---:|---:|---:|---:|

## 4. 还差 `film_both` 的那一截

`e8-16` 在最好的 guided 上已经是 0.76，`film_both` 第 1000 步是 0.82，第 2000 步是 0.87。8–16 像素的笔触，H/8 主干加半分辨率 24 通道就画得出来，不需要全分辨率编码器和 64 通道跳连。

`e4-8` 停在 0.32–0.41，`film_both` 是 0.79。4–8 像素在半分辨率上只有 2–4 个格子，最近邻放大后每个格子是 2×2 纯色。V2 头的空间核是 8 个独立的 3×3 深度卷积，修的是这个色块的边界，产生不了一道新的 4 像素笔触。`film_both` 放大之后仍有 24 通道的全分辨率可分离层（640×480 上 487 Mmac，整网里最贵的一层），颜料没有先压成 8 通道。

lapvar 比 0.17 对 0.39。guide 和 `to_guide` 都经过 ReLU 再相加，负向的锐化脉冲进不了全分辨率特征。

## 6. H/2 引导、5×5、乘法门控

`experiments/tiny_dw_vangogh_overfit_guide/`。仍是 V2 骨架、1000 步。对照是 V2 第 1000 步：23.55 dB / lapvar 比 0.10 / `e4-8` 0.32 / `e8-16` 0.64。

## 7. 主干停在哪一格

`experiments/tiny_dw_vangogh_overfit_trunk/`。1000 步，同一张 city、同一损失、seed 0。样本顺序 `b1_h4`、`b2_h8`、`b3_resid`。对照是 V2 第 1000 步（23.55 / 0.10 / 0.32 / 0.64）、`h2_guide`（23.95 / 0.09 / 0.47 / 0.71）和 `film_both`（25.59 / 0.39 / 0.79 / 0.82）。

| 臂 | 改动 |
|---|---|
| `b1_h4` | guided 主干停在 H/4：`enc1` 去掉 stride-2，res 和 InstanceNorm 留在 H/4，`dec_h4` 前面不再上采样，`h2_guide=16` 保留。26,303 参数，788 Mmac |
| `b2_h8` | `film_both` 再加一级 stride-2，残差混在 H/8。回到 H/2 skip 之前是两次最近邻，中间没有卷积。全分辨率 stem 和 64 通道跳连都留着。30,709 参数 |
| `b3_resid` | V2 上 `f + guide + f⊙g`，`g` 是零初始化的 8→8。25,111 参数 |

| 步 | `b1_h4` PSNR / lap / e4-8 / e8-16 | `b2_h8` | `b3_resid` |
|---:|---|---|---|
| 200 | 19.97 / 0.14 / 0.39 / 0.63 | 18.38 / 0.00 / 0.02 / 0.03 | 16.82 / 0.02 / 0.11 / 0.15 |
| 400 | 23.23 / 0.18 / 0.45 / 0.63 | 20.06 / 0.02 / 0.11 / 0.22 | 17.37 / 0.02 / 0.08 / 0.11 |
| 600 | 24.03 / 0.18 / 0.55 / 0.71 | 20.35 / 0.03 / 0.13 / 0.27 | 17.79 / 0.01 / 0.06 / 0.08 |
| 800 | 24.72 / 0.19 / 0.65 / 0.76 | 20.74 / 0.05 / 0.18 / 0.33 | 18.13 / 0.01 / 0.04 / 0.06 |
| 1000 | **25.05 / 0.22 / 0.68 / 0.78** | 21.19 / 0.06 / 0.22 / 0.38 | 18.44 / 0.01 / 0.04 / 0.06 |

终点损失：`b1_h4` 0.154（L1 0.0399，grad 0.0569），`b2_h8` 0.193（0.0633 / 0.0650），`b3_resid` 0.219（0.0884 / 0.0655）。checker：`b1_h4` 6.1e-6，`b2_h8` 1.1e-6，`b3_resid` 2.0e-7。教师的 checker 约 1e-6。

`b2_h8` 把「已知能做到」的那一端拆开了。`e4-8` 落到 0.22，比事先说的 0.4 还低，`e8-16` 也从 0.82 掉到 0.38。stem 和 H/2 跳连都在，内容特征的容量没有把笔触留住。残差所在的格子才是主因。它比 V2 还平，是因为 H/8 到 H/2 中间没有卷积：guided 的 H/8 主干在 H/4 仍有一层 `dec_h4`，所以 V2 的 `e8-16` 能到 0.64。这一臂最后 200 步 `e4-8` 只加了 0.04，按这个斜率走不到 0.7。

`b1_h4` 补上了这一截里的大半。相对只有 `h2_guide` 的 0.47，`e4-8` 到 0.68，`e8-16` 从 0.71 到 0.78，已经挨着 `film_both` 的 0.82。PSNR 25.05，离 `film_both` 的 25.59 还差 0.5 dB。lapvar 比从 0.09 抬到 0.22，教师那一档是 0.39：4–8 px 的笔触回来了，1–3 px 的锋口还没有。600→800 的 `e4-8` 加了 0.10，800→1000 只加了 0.03，再训一截补不满剩下的 0.11。checker 随笔触一起长到 6.1e-6，和 `shuffle_guide` 的 8.9e-6 同一档，采样上能看到短的、发块的笔触。H/4 的 3×3 行缓存是 20 KiB，这一臂多出来的算力是 res 的 135 Mmac 加上 `enc1` 的 67 Mmac。

`b3_resid` 第 0 步等于加法，第 200 步 `e4-8` 已经只有 0.11，之后一路降到 0.04。L1 还在降，梯度损失从第 200 步的 0.065 钉到第 1000 步的 0.066。零初始化没有把优化留在加法上，`g` 学到的是把颜料抹平。乘在放大后的颜料上，这条路放下。

下一步不再做 H/2 内容编码器。`b2_h8` 已经带着全分辨率 stem 和 64 通道跳连，细笔触还是没了。剩下的差距是 lapvar，也就是比 4 px 更细的那一档，再加上 `b1_h4` 带出来的 2 px 棋盘格。
